Brasa — propuesta de diseño

Carbón cálido + acento brasa. Pestañas en un carril lateral, bloques como tarjetas, Claude a un clic. Oscuro (izquierda) y claro (derecha).

  • Barra superior: logo, ruta actual en migas de pan (clic para saltar a una carpeta) y el botón Claude (abre Claude Code en esa carpeta, Ctrl+Mayús+C).
  • Carril lateral con las sesiones: nombre, carpeta y estado (gris inactiva, brasa = trabajando, verde = terminó). Las sesiones de Claude Code se marcan solas.
  • Bloques como tarjetas con una franja de color (verde bien, rojo error, brasa Claude), duración, y en los errores el botón Explicar con Claude.
  • Entrada redondeada con chips (carpeta, rama git) y un cursor-brasa que brilla, como el logo.
  • Barra de estado: shell, rama, estado de Claude y tema. Tipografía Segoe UI Variable + Cascadia Code (las de Windows, cero carga).
